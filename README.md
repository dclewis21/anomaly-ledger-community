# Anomaly Ledger Community

**Public discussion backend only** for [Anomaly Ledger](https://anomaly-ledger.pages.dev).

This repository exists so [Giscus](https://giscus.app) can power per-case comments and the Community hub on the private site repo (`dclewis21/anomaly-ledger`). It is **not** the site source.

## Why a satellite?

GitHub Discussions + Giscus require a **public** repository. The main ledger repo stays private.

## Categories (create in GitHub UI if missing)

| Category | Purpose |
| --- | --- |
| **Case threads** | Per-case Giscus threads (pathname mapping) |
| **Sightings** | Community sighting chatter — not verified |
| **Places tips** | Public-access tips only; no trespass coaching |
| **Case debates** | Debate / analysis of ledger cases |
| **Site feedback** | Bugs, UX, and **report / flag** posts for mods |

Settings → General → Features → Discussions → Manage categories.

## Moderation (Curt rails)

- UGC is not site endorsement or verified fact
- Hard remove: doxxing, threats, harassment, illegal coaching, trespass tips, spam
- Places: public land / published access only
- Living case comments ≠ official investigation file
- Operators may hide/remove posts and restrict access

Report path: open a discussion under **Site feedback** titled `Report: …`, or use GitHub’s report controls on the offending post.
